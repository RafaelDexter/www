## Descrição

Este repositório contém os programas desenvolvidos como parte da Atividade Prática Orientada (APO) da disciplina de Programação Para Ciência de Dados. Os programas foram implementados em Python, seguindo a temática de construção de algoritmos.

### Estrutura dos Arquivos

Os arquivos de código Python seguem a seguinte convenção de nomenclatura:
- **prg{número}.py**: onde `{número}` refere-se ao número da questão, e `.py` é a extensão do arquivo.

Alguns dos programas utilizam a interface gráfica Tkinter para a construção de GUIs (Graphical User Interface). As instruções para instalação e uso do Tkinter estão descritas abaixo.

---

## Instalação do Tkinter

### Windows

No Windows, o Tkinter já está incluído por padrão com o Python, não sendo necessário realizar nenhuma instalação adicional.

### Linux

Na maioria das distribuições Linux, o Tkinter pode ser instalado diretamente dos repositórios oficiais. No **Ubuntu**, por exemplo, ele pode ser instalado via linha de comando ou pelo "Software Center". O pacote necessário se chama `python3-tk`.

#### Instalação via terminal (Ubuntu):

```bash
sudo apt install python3-tk
```

Após a conclusão da instalação, você poderá executar Python e importar o Tkinter sem erros:

```python
Python 3.7.6
Type "help", "copyright", "credits" or "license" for more information.
>>> import tkinter
```

Agora você está pronto para criar aplicativos Python com Tkinter.

### macOS

No macOS, você pode instalar o Tkinter utilizando o Homebrew.

#### Instalação do Homebrew:

Para instalar o Homebrew, execute o seguinte comando no terminal:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Após instalar o Homebrew, você pode instalar o Python com:

```bash
brew install python3
```

Com o Python instalado, instale o Tkinter com o seguinte comando:

```bash
brew install python-tk
```
